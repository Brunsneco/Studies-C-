# Finalidade

Este repositório é destinado a treinamentos de linguagem C e C++, juntamente com integrações com o GitHub.

## Arquivos

### Fibonacci

O arquivo `Fibonacci/Fibonacci.cpp` contém uma implementação da sequência de Fibonacci. Ele preenche um vetor com a sequência de Fibonacci até um número máximo de termos especificado pelo usuário. O programa também verifica se o número de termos solicitado excede o tamanho máximo do vetor e trata possíveis overflows.

### IF_ELSE

O arquivo `IF_ELSE/IF_ELSE.cpp` contém um programa que lê duas notas, calcula a média e determina se o aluno está aprovado, reprovado ou se precisa fazer exame.

### Calc_values

O diretório `Calc_values` contém arquivos relacionados a operações básicas (soma, subtração, multiplicação e divisão) entre dois valores fornecidos pelo usuário. O arquivo `calc_values.cpp` é o principal e realiza as operações solicitadas.

### Sum_value

O arquivo `Sum_value/sum_value.cpp` contém um programa que solicita ao usuário dois valores numéricos e exibe a soma desses valores.

### Hello_name

O arquivo `Hello_name/main.cpp` contém um programa simples que solicita ao usuário o nome e exibe uma mensagem de boas-vindas.
